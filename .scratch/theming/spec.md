# Spec: 多风格界面皮肤 + 深色模式（theming）

**Status:** resolved（工单 01–06 全部完成，2026-08-28）

> 来源：一次性风格原型（throwaway prototype，含 5 套风格、variant 键 `brutal / editorial / neumorph / gradient / cyber`）→ grilling 设计树收敛（4 轮）。
> 范围：本 spec 只描述设计与拆分；实施前仍需一次明确 go-ahead。

## Problem Statement

使用者（个人生活 App 的单一使用者）目前只有一套浅色外观 + 可调主题色 + 深色开关，视觉风格单一。通过一次性原型已确认了 5 套满意的视觉风格（野兽派 / 编辑杂志风 / 新拟物派 / 现代渐变风 / 赛博朋克风），但原型是独立 throwaway 代码，尚未接入正式 App。需要把这 5 套风格作为「界面风格」正式接入数据与设置，让使用者在设置页切换，并保留深色模式；原「主题色」随本次改造移除。

## Solution

在数据与设置新增「界面风格」选择器（5 张缩略图卡片），选定后整套换肤；每套亮色风格配有专属暗色版，深色模式为全局开关，切换风格时保持明/暗状态。风格由 CSS 变量 + 组件级覆盖实现，统一收在独立样式文件，与业务样式分离。

## User Stories

1. 作为使用者，我能在「数据与设置」里看到 5 套界面风格的缩略图卡片，以便直观选择。
2. 作为使用者，我点击某套风格后，整个 App（首页总览 / 今日计划 / 工作计划 / 健身计划 / 饮食计划 / 数据与设置）立即换成该风格，以便立刻看到效果。
3. 作为使用者，切换风格后能收到一条「已切换至 X」轻提示，以便确认操作已生效。
4. 作为使用者，我选的风格会被持久化保存，刷新或重开浏览器后仍是上次选的风格，以便无需每次重设。
5. 作为使用者，首次打开时默认看到野兽派风格，以便有一个明确的初始外观。
6. 作为使用者，我仍能通过深色开关把当前风格切到其暗色版，以便在暗光环境下使用。
7. 作为使用者，切换风格时我的明/暗选择保持不变（深色开着就一直显示暗色版），以便无需重复开关。
8. 作为使用者，选择赛博朋克风格时它本身就是暗色、深色开关对其无额外变化，以便理解其恒暗特性。
9. 作为使用者，选择任一亮色风格（野兽派 / 编辑杂志 / 新拟物 / 现代渐变）并开启深色，会看到该风格专属的暗色版，以便每种风格都有统一协调的暗色形态。
10. 作为使用者，健身计划的训练部位（胸 / 肩 / 背 / 腿 / 有氧）颜色会随所选风格协调变化，以便部位信息在每套风格下都清晰可读。
11. 作为使用者，旧版本保存的主题色会被平滑迁移（不再有主题色，但其余数据不受影响），以便升级不丢数据。
12. 作为使用者，导出的备份包含我选的风格与深色设置、导入后能恢复，以便跨设备或重装后保持一致。
13. 作为使用者，切换风格不破坏体重趋势图——图表在暗色风格 / 深色模式下坐标轴与线条仍清晰可读，以便数据展示始终正常。
14. 作为使用者，风格缩略图始终显示亮色版（不随深色开关跳变），以便我稳定辨识各风格。

## Implementation Decisions

### 数据模型与迁移

- 设置结构改为 `settings = { nickname, theme, darkMode }`；新增 `theme`，白名单为 `brutal | editorial | neumorph | gradient | cyber`，默认 `brutal`；移除 `themeColor` 字段、预设色板常量及其设置函数。
- 迁移：旧数据丢弃 `themeColor`；`theme` 缺失或非法时回落 `brutal`；`darkMode` 原样保留。深色默认（新用户）= 关。

### 主题引擎

- `applyTheme()` 作为唯一「设置 → 渲染」转换点：据 `theme` + `darkMode` 在 `<body>` 上写 `data-skin`（风格键）与 `data-theme="dark"`（暗色），不再写主题色变量。
- 深色为**全局单一布尔**：切风格不重置明/暗；赛博朋克恒暗，深色开关对其无额外效果（该风格下开关视为无效）。

### 皮肤实现

- 每套风格 = 一组 CSS 变量（`--accent` 取代原主题色变量，另补 `--on-accent`、`--radius-sm`、`--bar-bg`、`--chart-fill`、`--font-display`、`--shadow-inset`、`--nav-active-*` 等）+ 组件级覆盖，按 App 真实组件类名重写（卡片 / 按钮 / 分段控件 / 计划卡 / 月历格 / 图表容器等）。
- 4 套亮色风格各附 `[data-theme="dark"]` 暗色覆盖；赛博朋克恒暗、无额外暗色。
- 视觉方向（grilling 定稿）：
  - 野兽派：cream 底 + 粗黑边 + 橙 accent + 硬阴影 + 等宽字体；**暗色版 = 沥青黑 + 荧光橙**。
  - 编辑杂志：衬线大标题 + 强留白 + 朱红 accent + 细线编号；**暗色版 = 墨夜版（墨黑底 + 米白衬线 + 朱红提亮 + 暗金/米白细线）**。
  - 新拟物：浅灰同色浮雕 + 双阴影 + 紫 accent；**暗色版 = 暗灰浮雕（深黑 + 亮灰双阴影 + 紫提亮）**。
  - 现代渐变：彩色径向渐变 + 毛玻璃 + 紫粉青渐变 accent；**暗色版 = 暗夜霓虹渐变（深蓝紫光斑 + 半透明深玻璃 + 提亮渐变）**。
  - 赛博朋克：霓虹（青/品红）+ 扫描线 + 斜切卡片，恒暗。
- 样式变量统一为 `--accent`（原主题色变量全局改名），外壳加载新增的独立样式文件。

### 设置界面

- 新增「界面风格」卡片：5 张缩略图（风格名 + 微缩配色/质感预览），单选、当前高亮、恒显亮色版。
- 交互：点击即时应用 + toast「已切换至 X」；删除主题色色块与取色器；深色开关保留为独立开关（位于「基础设置」）。

### 语义色（训练部位）

- 训练部位色按风格主题化：5 套各一套，暗色版沿用同风格部位色并微调亮度保证暗底可读；由 agent 自动设计，随风格预览一并给使用者确认。

### 图表适配

- 图表适配器内部明暗判断改为「皮肤为暗色 或 深色开启」（等价于 `darkMode || theme === 'cyber'`）；主色读取当前皮肤 accent，替换写死的主题色。

## Testing Decisions

- 好测试标准：只测外部行为（设置 → 渲染的可见结果、持久化结果），不测内部实现细节（具体 CSS 值、DOM 结构）。
- 主缝：`applyTheme()` —— 给定 `settings.theme` + `darkMode`，断言 `<body>` 的 `data-skin` / `data-theme` 属性值（注入假 document，沿用现有测试基座）。
- 设置函数：`setTheme()` 断言写入 `theme`、触发持久化与主题应用。
- 迁移：`normalize()` 断言旧数据（含 `themeColor`、缺 `theme`、非法 `theme`）正确回落 `brutal`、`darkMode` 保留。
- 图表：沿用图表适配器缝，断言暗色判断与主色来源随皮肤 / 深色变化。
- 先例：`applyTheme`/`normalize` 既有用例、`setThemeColor`/`setDarkMode` 同款 setter 断言、图表适配器内部纯函数 / 委托断言、假 document mock。
- 回归：更新既有断言中依赖主题色的用例与 mock，并新增主题切换（含每套暗色版）用例。

## Out of Scope

- 不重开 ADR-0001（v1.1 领域简化）、ADR-0002（图表适配器缝）。
- 不做主题的运行时编辑 / 自定义（使用者只能 5 选 1，不能自建新皮肤）。
- 不提供「跟随系统深色」（prefers-color-scheme 自动切换）——深色仅手动开关。
- 不在首页 / 顶栏新增快捷切换入口——风格选择仅在数据与设置。
- 不改动业务数据模型（今日计划 / 工作计划 / 健身 / 饮食的数据结构不变）。
- 不重做原型未覆盖的其他页面视觉（本次只把既有 5 套皮肤落地到现有组件）。

## Further Notes

- 术语表 gap：现有领域术语表无「界面风格 / 皮肤（Skin）」词条；建议落地后补一条 glossary。本 spec 暂用「界面风格」指代整套可切换的视觉皮肤，用「风格键（theme key）」指代 `brutal / editorial / neumorph / gradient / cyber`。
- 迁移代价：老使用者升级后主题色丢失、外观变为野兽派（符合「不保留原版」决策），需在变更日志记录。
- 4 套暗色版为本次新增视觉设计量（原型仅亮色版），方向已在 grilling 定稿。
- 训练部位色按风格主题化由 agent 自动设计，实施时须连同 5 套风格一起给使用者预览确认。
