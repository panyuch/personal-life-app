# 03: 第一块摘要卡结构对齐（编号 + 数字条）

**What to build:** 首页第一块五张摘要卡对齐风格原型：每张卡标题带 `data-no` 编号（01–05）；工作计划卡用数字条呈现（计划数 / 内容数 / 已完成数）；健身计划卡显示今天有无训练 + 最近体重；饮食计划卡显示今日是否已记录 + 今日热量。各卡整卡可点击进入对应模块。从使用者视角：第一块卡片网格的呈现方式与原型一致，数字与各模块真实数据一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 五张卡标题带编号 01–05，编辑杂志风格下编号前缀可见
- [ ] 工作计划卡数字条与工作计划模块真实数字一致
- [ ] 健身卡训练名 / 最近体重与健身模块一致
- [ ] 饮食卡热量与饮食模块当日汇总一致
- [ ] 每张卡整卡可点击跳转对应模块
- [ ] 今日计划卡勾选、快速备忘卡增删仍可用
